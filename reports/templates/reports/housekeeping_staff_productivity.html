Calculation notes: room release counts come from successful CleaningLog records, which are created after inspection approval. Rework counts each assignment once if it had one or more failed inspections. First-inspection pass rate uses the earliest inspection for each assignment. Cleaning duration is measured from started_at to completed_at; because rework may update completed_at, this reflects the latest submission timestamp and can include time awaiting inspection. Deadline performance compares that submission with the original deadline or the latest approved extension deadline. Historical records without timestamps or deadlines are excluded from the relevant averages.
