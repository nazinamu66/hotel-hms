How to Read This Report

Actual check-ins use folio creation/check-in timestamps. Actual checkouts include only closed folios, because open folios may carry an expected checkout timestamp. Repeat guests are guests with an earlier room folio before the selected period.

This first release does not estimate check-in duration, checkout duration, enquiry conversion or complaints. Those require reliable event timestamps or dedicated records.
